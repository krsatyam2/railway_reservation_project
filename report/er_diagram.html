2. Individual Relational Tables (15 Tables)

1. USERS

Registered system users

ColumnTypeKey
user_idINTEGERPK
nameVARCHAR(100)
emailVARCHAR(100)UNIQUE
phoneVARCHAR(20)
passwordVARCHAR(255)
created_atTIMESTAMP

2. STATIONS

Railway network stations

ColumnTypeKey
station_idINTEGERPK
station_nameVARCHAR(100)
station_codeVARCHAR(10)UNIQUE
cityVARCHAR(100)
stateVARCHAR(100)

3. TRAINS

Master train details & routes

ColumnTypeKey
train_idINTEGERPK
train_nameVARCHAR(100)
train_numberVARCHAR(20)UNIQUE
source_station_idINTEGERFK → stations
destination_station_idINTEGERFK → stations
running_daysVARCHAR(100)
total_seatsINTEGERDEFAULT 100

4. TRAIN_STOPS

Intermediate halts and sequence numbers

ColumnTypeKey
stop_idINTEGERPK
train_idINTEGERFK → trains
station_idINTEGERFK → stations
sequence_noINTEGERNOT NULL
arrival_timeTIME
departure_timeTIME
halt_durationINTEGERMinutes
distance_from_sourceINTEGERKm

5. COACH_CLASSES

Class tiers (SL, 3A, 2A, CC)

ColumnTypeKey
class_idINTEGERPK
class_codeVARCHAR(10)NOT NULL
class_nameVARCHAR(50)NOT NULL
fare_per_kmNUMERIC(6,2)

6. COACHES

Train coach composition

ColumnTypeKey
coach_idINTEGERPK
train_idINTEGERFK → trains
coach_numberVARCHAR(20)e.g. A1, B1
total_seatsINTEGERDEFAULT 72

7. SEATS

Physical seat inventory

ColumnTypeKey
seat_idINTEGERPK
train_idINTEGERFK → trains
coach_idINTEGERFK → coaches
class_idINTEGERFK → coach_classes
seat_numberVARCHAR(10)NOT NULL
berth_typeVARCHAR(20)'Seat'

8. TRAIN_RUNS

Scheduled run instance by date

ColumnTypeKey
run_idINTEGERPK
train_idINTEGERFK → trains
run_dateDATENOT NULL
journey_dateDATE
source_stationVARCHAR(100)
destination_stationVARCHAR(100)

9. BOOKINGS

Master booking order per PNR

ColumnTypeKey
booking_idINTEGERPK
user_idINTEGERFK → users
train_idINTEGERFK → trains
run_idINTEGERFK → train_runs
pnrVARCHAR(20)UNIQUE
booking_statusVARCHAR(20)'Confirmed'

Passenger profiles

ColumnTypeKey

user_idINTEGERFK → users
nameVARCHAR(100)NOT NULL

ColumnTypeKey

seat_idINTEGERFK → seats

ColumnTypeKey
